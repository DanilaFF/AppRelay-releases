AppRelay — программа для Mac. Она смотрит, какие приложения и версии стоят на вашем старом iPhone, скачивает эти версии с серверов Apple на ваш Apple ID и устанавливает на новый iPhone. Так можно перенести СберБанк Онлайн, Т-Банк, Альфа-Банк, ВТБ и другие приложения, которые удалены из App Store.

### Как перенести приложения

1. Скачайте **AppRelay.dmg** и перетащите AppRelay в «Программы».
2. Подключите оба iPhone к Mac кабелем, разблокируйте и нажмите «Доверять».
3. Отметьте приложения и нажмите «Перенести».
4. Войдите в Apple ID, с которого приложения скачивались.

**Первый запуск:** macOS попросит подтвердить запуск. Откройте AppRelay → «Готово» → Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть». Это нужно один раз. Дальше обновления приходят сами — AppRelay предложит «Обновить» при запуске.

### Условия

- Mac на macOS 14 или новее (Apple Silicon и Intel), кабели для обоих iPhone.
- Приложение должно стоять на старом iPhone и быть скачано на ваш Apple ID.
- Переносятся сами приложения; данные внутри них — нет (войдите в аккаунты заново).
- Пароль Apple ID передаётся только Apple и нигде не сохраняется.
